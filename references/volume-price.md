# 量价八阶律与核心概念速查表

> **用途**：快速查询量价八阶律的定义、量化标准、位置含义和操作策略，以及10个核心量价概念的量化标准。详细分析请使用 `volume-price-analysis` Skill。
> **数据来源**：《证券投资技术分析》、东方财富网《量价风云录》、雪球《量价关系分析》、抖音百科《八阶律》等。

## 一、量能量化标准体系

| 指标 | 严重缩量 | 缩量 | 正常 | 温和放量 | 明显放量 | 巨量 | 极端放量 |
|------|----------|------|------|----------|----------|------|----------|
| 量比 | <0.5 | 0.5-0.8 | 0.8-1.5 | 1.5-2.5 | 2.5-5 | 5-10 | >10 |
| 换手率（主板） | <1% | 1%-3% | 3%-7% | 7%-15% | 15%-25% | >25% | — |
| 成交量 | <5日均量50% | 50%-80% | 80%-120% | 120%-150% | 150%-300% | 300%-500% | >500% |

> 注：创业板/科创板因20%涨跌幅限制，换手率标准可适当上浮50%。

### 量比+换手率组合判断

| 组合 | 含义 | 可信度 |
|------|------|--------|
| 量比>2 + 换手率5%-10% | 健康放量突破，有真实资金进场 | 高 |
| 量比>3 + 换手率>15% | 巨量博弈，多空分歧极大 | 中（谨慎） |
| 量比大 + 换手率低 | 可能对倒/虚量，主力自买自卖 | 低（不可信） |
| 量比<0.8 + 换手率<1% | 极度缩量，交投清淡 | 高（地量特征） |

## 二、量价八阶律查询表

### 阶律1：量增价升（健康上涨）

| 项目 | 内容 |
|------|------|
| **定义** | 成交量逐步放大，股价同步上涨 |
| **量化标准** | 连续3日以上，成交量递增（每日量比≥1.2），股价每日收盘价递增 |
| **量价关系** | 量价同向，正相关 |
| **市场逻辑** | 买盘力量持续增强，资金不断涌入推高股价，"上涨有量是真金" |
| **低位含义** | 主力建仓完毕开始拉升，最佳买入信号 |
| **上涨途中含义** | 趋势健康延续，可持股或加仓 |
| **高位含义** | 需警惕，可能是最后一波拉升（放量赶顶），量能突然暴增时尤甚 |
| **操作策略** | 低位：积极买入重仓；上涨途中：持股待涨回踩加仓；高位：减仓50% |
| **止损** | 转为量增价平或量缩价升时减仓 |
| **可靠性** | 高（最健康的上涨形态） |
| **失败模式** | 高位放量赶顶（涨幅递减）；对倒放量（自买自卖）；单日放量不代表趋势 |

### 阶律2：量增价平（多空分歧）

| 项目 | 内容 |
|------|------|
| **定义** | 成交量放大，但股价基本不涨（横盘） |
| **量化标准** | 连续3日量比≥1.5，但股价涨跌幅<±2% |
| **量价关系** | 量增而价不涨，背离前兆 |
| **市场逻辑** | 买盘在进场但卖盘也在涌出，双方力量均衡导致股价不涨，"放量不涨"是危险信号 |
| **低位含义** | 可能是主力吸筹（压价吸货），也可能是多空分歧，需观察 |
| **上涨途中含义** | 上升中继整理，洗盘换手，后续继续量增价升则健康 |
| **高位含义** | 最危险！主力出货典型信号——"高位放量不涨=主力出货" |
| **操作策略** | 低位：观察等待方向；上涨途中：持股观察；高位：果断减仓50%以上，次日低开清仓 |
| **止损** | 高位量增价平后出现量增价跌，立即清仓 |
| **可靠性** | 高位时高，低位时中（需区分吸筹和出货） |
| **失败模式** | 低位压价吸筹（后续暴涨）；上涨中继放量洗盘；需结合位置判断 |

### 阶律3：量增价跌（恐慌抛售/出货）

| 项目 | 内容 |
|------|------|
| **定义** | 成交量放大，股价下跌 |
| **量化标准** | 连续2日以上量比≥1.5，股价每日收盘价递减（跌幅≥2%） |
| **量价关系** | 量价反向，负相关 |
| **市场逻辑** | 卖盘力量远大于买盘，大量筹码涌出但买盘不足，"放量下跌不言底" |
| **低位含义** | 可能是最后一跌（恐慌盘涌出，割肉盘出清），也可能继续下跌 |
| **上涨途中含义** | 上升趋势中的放量回调，快速收回则是洗盘，持续则趋势反转 |
| **高位含义** | 最明确的出货信号！"高位放量下跌=主力出货"，果断离场 |
| **下跌途中含义** | 恐慌抛售加剧，下跌趋势延续 |
| **操作策略** | 低位：不急于抄底，观察地量企稳；上涨途中：减仓观察3日内是否收回；高位：果断清仓；下跌途中：持币观望不抄底 |
| **止损** | 任何位置的量增价跌都应先减仓控制风险 |
| **可靠性** | 高位时极高，下跌途中高，低位时中（可能是最后一跌） |
| **失败模式** | 低位最后一跌（割肉在最低点）；上涨途中放量洗盘；放量假跌（盘中跌收盘收回） |

### 阶律4：量平价升（惜售上涨）

| 项目 | 内容 |
|------|------|
| **定义** | 成交量基本不变（持平），股价上涨 |
| **量化标准** | 连续3日量比0.8-1.2，股价每日收盘价递增 |
| **量价关系** | 量平价升，缩量上涨的温和形态 |
| **市场逻辑** | 持股者惜售，卖盘很少，不需要大量买盘就能推高股价，"量平价升=锁仓上涨"，主力控盘度高 |
| **低位含义** | 主力吸筹完毕、筹码锁定，即将启动拉升，买入信号 |
| **上涨途中含义** | 主力锁仓拉升，趋势健康，可持股 |
| **高位含义** | 需警惕，可能是"无量赶顶"——跟风不足，随时见顶 |
| **下跌途中反弹** | 无量反弹，持续性差，"反弹无量是虚火" |
| **操作策略** | 低位：买入（主力控盘度高）；上涨途中：持股待涨；高位：减仓；下跌反弹：不追 |
| **可靠性** | 中高（需区分主力控盘和跟风不足） |
| **失败模式** | 高位无量赶顶；下跌途中无量反弹；需与量缩价升区分（前者量能持平，后者量能萎缩） |

### 阶律5：量平价平（盘整观望）

| 项目 | 内容 |
|------|------|
| **定义** | 成交量和股价都基本不变，横盘整理 |
| **量化标准** | 连续5日以上量比0.8-1.2，股价涨跌幅<±3% |
| **量价关系** | 量价均平，多空均衡 |
| **市场逻辑** | 市场参与度低，多空双方都在观望，"量能无波势不变" |
| **低位含义** | 底部横盘，主力可能悄悄吸筹，"底部长期无量"是蓄势信号 |
| **上涨途中含义** | 上升中继整理，洗盘换手，后续方向选择 |
| **高位含义** | 高位横盘，主力可能悄悄出货，需警惕 |
| **下跌途中含义** | 下跌中继，后续可能继续下跌 |
| **操作策略** | 低位：观察可小仓位埋伏；上涨途中：持股观察；高位：减仓；下跌途中：持币观望。总原则：盘整市不操作，等待方向选择 |
| **可靠性** | 中（方向不确定，需等待突破确认） |
| **失败模式** | 横盘时间过长资金效率低；横久必跌；高位横盘温水煮青蛙 |

### 阶律6：量平价跌（阴跌不止）

| 项目 | 内容 |
|------|------|
| **定义** | 成交量基本不变，股价持续下跌 |
| **量化标准** | 连续5日以上量比0.8-1.2，股价每日收盘价递减 |
| **量价关系** | 量平价跌，阴跌形态 |
| **市场逻辑** | 卖盘持续涌出但买盘不接，股价缓慢下跌，"阴跌无底"，每天跌一点不知不觉跌幅巨大 |
| **低位含义** | 可能是最后一跌，也可能继续阴跌，需观察地量 |
| **高位含义** | 主力缓慢出货，"温水煮青蛙"，跌幅不知不觉扩大 |
| **下跌途中含义** | 典型阴跌走势，下跌趋势延续 |
| **操作策略** | 任何位置的量平价跌都应减仓或离场；低位：观察等待地量企稳；高位/下跌途中：果断离场，"阴跌不止，早走早好"。禁忌：阴跌中"越跌越买"（摊低成本陷阱） |
| **可靠性** | 中高（阴跌杀伤力大） |
| **失败模式** | 阴跌中等反弹结果越等越深；阴跌末端突然放量暴跌（最后一跌）然后见底 |

### 阶律7：量缩价升（背离预警）

| 项目 | 内容 |
|------|------|
| **定义** | 成交量萎缩，股价上涨 |
| **量化标准** | 连续3日量比<0.8（较前5日均量萎缩20%以上），股价每日收盘价递增 |
| **量价关系** | 量价背离（顶背离前兆） |
| **市场逻辑** | 股价上涨但买盘在减少，没有成交量配合的上涨是"虚涨"，跟风不足，"量缩价升看格局" |
| **低位含义** | 可能是主力锁仓后的启动（筹码高度集中），也可能是反弹无力 |
| **上涨途中含义** | 需区分：控盘股缩量上涨健康（锁仓拉升）；非控盘股缩量上涨危险（跟风不足） |
| **高位含义** | 最危险！"高位缩量上涨=无量赶顶"，行情末端诱多，随时反转 |
| **下跌途中反弹** | 典型无量反弹，"反弹无量是虚火"，持续性极差 |
| **操作策略** | 低位：观察，控盘股可小仓位参与；上涨途中：控盘股持股，非控盘股减仓；高位：果断减仓；下跌反弹：不追，反弹即减仓机会 |
| **可靠性** | 高位时高，其他位置需结合控盘度判断 |
| **失败模式** | 主力高度控盘股缩量上涨健康；低位缩量上涨可能是吸筹完毕启动；需与量平价升区分 |

### 阶律8：量缩价跌（缩量调整/下跌末期）

| 项目 | 内容 |
|------|------|
| **定义** | 成交量萎缩，股价下跌 |
| **量化标准** | 连续3日量比<0.8，股价每日收盘价递减 |
| **量价关系** | 量缩价跌，下跌动能衰减 |
| **市场逻辑** | 卖盘在减少，下跌过程中成交量萎缩说明抛压在减轻，"缩量回踩稳如山，洗盘过后更可期" |
| **低位含义** | 最积极的信号！"地量见地价"，抛压枯竭，底部临近，可分批低吸 |
| **上涨途中含义** | 健康的缩量回调（洗盘），是加仓机会 |
| **高位含义** | 可能是下跌初期（买盘不足），也可能是短暂回调，需观察 |
| **下跌途中含义** | 下跌动能衰减，但"缩量下跌还有下跌"，未到地量前不抄底 |
| **操作策略** | 低位：分批低吸，"地量见地价，黄金坑里挖"；上涨途中：加仓（缩量回踩是买点）；高位：减仓观察；下跌途中：观察等待地量企稳。关键：缩到极致（地量）才是见底信号 |
| **可靠性** | 低位+地量时高，上涨途中时高，下跌途中时中（需等地量） |
| **失败模式** | "缩量下跌还有下跌"——缩量不代表立即见底；需等到地量（缩到极致）才是见底信号，普通缩量不够 |

## 四、10个核心量价概念速查表

### 概念1：地量见地价

| 项目 | 内容 |
|------|------|
| **定义** | 成交量萎缩到极致（地量）后，股价也到达底部（地价），随后反转上涨 |
| **量化标准** | 成交量缩至近60日均量的30%以下，或创近3个月新低；股价同步创阶段新低 |
| **级别可靠性** | 周线/月线 >> 日线 |
| **市场逻辑** | 该卖的人都卖完了，抛压枯竭，少量买盘就能推高股价 |
| **操作策略** | 长期下跌后：分批低吸（3-5批），不一次性满仓；上涨途中回调：加仓；需等待放量上涨确认——"地量之后见地价，放量上涨才是真底" |
| **止损** | 地量后继续放量下跌，说明不是底，止损 |
| **失败模式** | "地量之后还有地量"；日线骗线多；无量反弹可能是假底；小盘股常年地量不适用 |

### 概念2：天量见天价

| 项目 | 内容 |
|------|------|
| **定义** | 成交量放大到极致（天量）后，股价也到达顶部（天价），随后反转下跌 |
| **量化标准** | 成交量放大至近60日均量的3倍以上，或创近3个月新高；股价同步创阶段新高 |
| **级别可靠性** | 周线/月线 >> 日线 |
| **市场逻辑** | 该买的人都买了，买盘枯竭，大量获利盘涌出，顶部自然形成 |
| **操作策略** | 长期上涨后：果断减仓50%以上；天量后股价不涨（放量滞涨）：清仓；观察3日，不能继续放量创新高则确认见顶。禁忌：天量时追高买入 |
| **失败模式** | "天量之后还有天量"（强趋势连续放天量）；低位天量是建仓不是顶；上涨途中天量换手后继续上涨（换庄）；日线骗线多 |

### 概念3：量价背离（顶背离/底背离）

| 项目 | 内容 |
|------|------|
| **顶背离定义** | 股价创新高，但成交量未同步放大（甚至缩量），形成"价升量不升" |
| **底背离定义** | 股价创新低，但成交量未同步放大（甚至缩量），形成"价跌量不增" |
| **量化标准** | 股价创近20日新高/新低，成交量低于前高/前低点时的成交量 |
| **级别可靠性** | 周线 > 日线 > 60分钟；多级别共振更可靠 |
| **市场逻辑** | 价格趋势与资金趋势不一致，顶背离=买方力量减弱，底背离=卖方力量减弱 |
| **操作策略** | 高位顶背离：减仓50%，确认后清仓；低位底背离：分批建仓30%-50%；需等待价格确认（顶背离后跌破关键支撑，底背离后突破关键压力）。禁忌：背离出现后立即满仓/清仓 |
| **失败模式** | "背离之后还有背离"；背离后价格不反转继续原趋势；日线骗线多需多级别共振 |

### 概念4：堆量（量堆）形态

| 项目 | 内容 |
|------|------|
| **定义** | 成交量连续多日放大，形成一个"量堆"（像一座小山），然后缩量 |
| **量化标准** | 连续5-10日成交量≥均量1.5倍，形成量堆；随后缩量到均量以下 |
| **分类** | 低位堆量（建仓）、高位堆量（出货）、上涨途中堆量（换手/拉升） |
| **市场逻辑** | 资金在一段时间内持续进场或离场，低位堆量=主力持续建仓，高位堆量=主力持续出货 |
| **操作策略** | 低位堆量：关注，堆量后缩量回调不破低点时买入；上涨途中堆量：持股，堆量后缩量回踩加仓；高位堆量：减仓50%以上。关键：堆量后缩量回调的低点不破堆量启动点 |
| **失败模式** | 高位对倒堆量（自买自卖制造假象）；堆量后缩量回调跌破启动点（建仓失败）；堆量不够大主力持仓不足 |

### 概念5：放量突破与缩量回踩

| 项目 | 内容 |
|------|------|
| **放量突破定义** | 股价突破关键压力位（前高、均线、趋势线）时，成交量≥均量1.5-2倍 |
| **缩量回踩定义** | 突破后股价回踩突破位时，成交量萎缩到均量以下（量比<0.8） |
| **标准组合** | 放量突破 → 缩量回踩不破 → 再次放量上涨（最佳买入模式） |
| **市场逻辑** | 放量突破=买盘消化所有卖盘，突破有效；缩量回踩=抛压不重，持股者惜售，突破位从压力变支撑 |
| **操作策略** | 放量突破时：买入30%-50%；缩量回踩不破时：加仓至80%（最佳买点）；再次放量上涨时：加满仓。止损：缩量回踩跌破突破位3%，假突破止损。禁忌：缩量突破（无量突破）不追 |
| **失败模式** | 假突破（突破后快速跌回）；无量突破（可靠性低）；回踩时放量（抛压重可能跌破）；回踩幅度过大（>5%说明突破无效） |

### 概念6：量比战法（量比指标用法）

| 项目 | 内容 |
|------|------|
| **定义** | 量比=当日每分钟平均成交量 / 过去5日每分钟平均成交量 |
| **量比分级** | <0.5严重缩量 / 0.5-0.8缩量 / 0.8-1.5正常 / 1.5-2.5温和放量 / 2.5-5明显放量 / 5-10放巨量 / >10极端放量 |
| **市场逻辑** | 实时衡量当日成交量相对近期平均水平的放大/萎缩程度，"量比看热度" |
| **位置含义** | 低位量比>2.5+股价上涨=资金进场；高位量比>5+股价不涨=主力出货；上涨途中量比1.5-2.5=健康放量；下跌途中量比>2.5=恐慌抛售；量比>10=极端放量趋势末期 |
| **操作策略** | 盘中选股：量比>2.5 + 涨幅1%-5% + 股价站稳20日线 → 分时均线附近分批介入；止损：开盘价下方2%。关键：看量比曲线与分时均价线配合，不能只看开盘瞬间 |
| **失败模式** | 开盘量比高但后续快速回落（早盘放量午盘缩量）；量比大+换手率低=对倒虚量；量比>10极端放量常是趋势末期；单看量比无意义需结合位置和方向 |

### 概念7：换手率分析（低/中/高/巨量换手）

| 项目 | 内容 |
|------|------|
| **定义** | 换手率=当日成交量 / 流通股本 × 100% |
| **分级（主板）** | <3%低换手（交易清淡）/ 3%-7%中换手（交易活跃）/ 7%-15%高换手（高度活跃）/ >15%巨量换手（极端活跃） |
| **创业板/科创板** | 标准上浮50% |
| **市场逻辑** | 反映交易活跃程度和筹码交换频率，低换手=筹码稳定，高换手=多空分歧大 |
| **位置含义** | 低位低换手=筹码锁定底部区域；低位高换手=主力建仓或换庄；上涨途中中换手=健康换手；上涨途中高换手=主力换手或出货；高位高换手/巨量换手=主力派发；高位低换手=主力锁仓或无人接盘 |
| **操作策略** | 低位低换手：观察等待放量；低位高换手：关注可能建仓；上涨途中中换手：持股；高位高换手：减仓50%+；高位巨量换手：清仓 |
| **失败模式** | 小盘股常年高换手（流通盘小）；新股/次新股换手率普遍偏高；高换手不一定是出货也可能是换庄；需结合位置判断 |

### 概念8：成交量均线（VOL MA5/VOL MA10）

| 项目 | 内容 |
|------|------|
| **定义** | VOL MA5=5日成交量均线；VOL MA10=10日成交量均线 |
| **量能金叉** | VOL MA5上穿VOL MA10（短期量能放大） |
| **量能死叉** | VOL MA5下穿VOL MA10（短期量能萎缩） |
| **量价共振** | 股价金叉 + 量能金叉同时出现（最强买入信号） |
| **市场逻辑** | 平滑单日成交量波动，反映量能趋势，量能金叉=资金进场，量能死叉=资金离场 |
| **操作策略** | 量能金叉+价格金叉：积极买入（量价共振）；量能金叉+价格未金叉：观察等待价格确认；量能死叉+价格死叉：果断卖出；量能死叉+价格未死叉：减仓预警；量价背离（价涨量缩）：减仓 |
| **失败模式** | 量能金叉后快速萎缩（一日游放量）；价格金叉但量能死叉（无量上涨可靠性低）；高位量能金叉可能是出货 |

### 概念9：分时量峰分析

| 项目 | 内容 |
|------|------|
| **定义** | 分时图中成交量柱状图的尖峰（放量时刻） |
| **攻击量峰** | 股价拉升时出现的放量尖峰（量峰高度≥均量3倍） |
| **出货量峰** | 股价下跌时出现的放量尖峰 |
| **对倒量峰** | 量峰巨大但股价不涨不跌（主力对倒） |
| **量峰形态** | 单峰、双峰、多峰、量峰递增/递减 |
| **市场逻辑** | 反映盘中资金实时动向，攻击量峰=主力主动买入，出货量峰=主力主动卖出 |
| **位置含义** | 早盘攻击量峰=当天偏强；尾盘攻击量峰=可能做收盘价（诱多）；早盘出货量峰=当天偏弱；尾盘出货量峰=次日大概率低开 |
| **操作策略** | 早盘攻击量峰+站稳分时均线：可跟进；拉升有量+回调缩量：健康持股；放量跳水+无力反弹：减仓/清仓；尾盘快速拉升+放量对倒：不追可能诱多 |
| **失败模式** | 对倒量峰（自买自卖股价不涨）；尾盘拉升量峰是做收盘价；量峰后量能快速萎缩拉升不可持续；高位攻击量峰可能是诱多 |

### 概念10：放量滞涨与缩量上涨的区别

| 特征 | 放量滞涨 | 缩量上涨 |
|------|----------|----------|
| **成交量** | 放大至均量1.5倍以上 | 萎缩至均量80%以下 |
| **股价表现** | 涨幅<1%，或冲高回落收长上影 | 持续上涨，涨幅>2% |
| **量价关系** | 量增价不涨 | 量缩价涨 |
| **本质** | 抛压沉重，主力出货 | 跟风不足或主力锁仓 |
| **低位含义** | 主力压价吸筹，关注 | 主力锁仓启动，买入 |
| **上涨途中含义** | 上升中继/换庄，观察 | 锁仓拉升，持股 |
| **高位含义** | 主力出货，清仓 | 无量赶顶，减仓 |
| **下跌途中含义** | 恐慌抛售，不抄底 | 无量反弹，不追 |

> 核心口诀："低位缩量回调皆为洗盘，高位放量震荡皆为出货"
